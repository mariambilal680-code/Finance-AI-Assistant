# Finance-AI-Assistant# 💰 Finance AI Assistant

A Transformer-based conversational AI chatbot designed to answer basic finance-related questions in simple and understandable language.

This project uses a pretrained language model and system prompts to create an interactive Finance AI Assistant.

## 🚀 Project Demo

**Live Gradio Demo:**  
https://ee906bacdf6d4c979e.gradio.live/

*Note: The demo link may expire when the Google Colab session ends.*

## 🎯 Project Objectives

- Build an interactive finance chatbot.
- Understand how pretrained Transformer models work.
- Use system prompts to guide chatbot responses.
- Maintain conversation history.
- Create a chatbot interface using Gradio.

## 🛠️ Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- Qwen2.5-0.5B-Instruct
- Gradio
- Google Colab

## 🤖 Model Information

**Model:** `Qwen/Qwen2.5-0.5B-Instruct`

The project uses a pretrained instruction-following language model for generating conversational responses. It is used for inference and has not been fine-tuned on a finance dataset.

## ⚙️ How to Run

1. Open the project notebook in Google Colab.
2. Make sure the required libraries are installed.
3. Run the notebook cells in order.
4. Load the pretrained model and tokenizer.
5. Launch the Gradio interface.
6. Start asking finance-related questions!

## 💡 Example Questions

- Explain stocks and bonds in simple language.
- What is compound interest?
- What is the difference between saving and investing?
- Explain financial risk.

## 📚 Key Learnings

Through this project, I practiced:

- Loading pretrained Transformer models.
- Understanding tokenization.
- Working with system prompts.
- Managing conversational history.
- Generating responses using `model.generate()`.
- Building interactive AI applications with Gradio.
